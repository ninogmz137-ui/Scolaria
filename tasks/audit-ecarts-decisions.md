Autre constat, hors liste, à vous soumettre : `ConnexionScreen` cherche le rôle dans une table `users` qui **n'existe pas** (c'est `profiles`) ; la recherche échoue donc toujours et l'écran retombe sur le rôle écrit dans les **métadonnées du compte, modifiables par la personne** (`supabase.auth.updateUser`). Conséquence : un parent pourrait se faire afficher l'interface enseignant. **Aucune donnée n'est exposée** (la base ne regarde que `profiles.role`, verrouillé), c'est de l'affichage. Correction proposée (petite, côté app) : lire `profiles.role`. À décider.
